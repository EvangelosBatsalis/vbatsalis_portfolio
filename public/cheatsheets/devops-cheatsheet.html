// Git
⎇ Branches & History
git log --oneline --graph --allVisual branch history
git branch -vvBranches + tracking info
git checkout -b feature/x origin/mainΝέο branch από remote
git switch -c feature/xModern branch create
git branch -d feature/x && git push origin --delete feature/xDelete local + remote
git stash push -m "WIP: login"Stash με message
git stash popRestore stash
git cherry-pick abc1234Πάρε specific commit
↩ Undo & Fix
git revert HEAD~1Undo last commit (safe) SAFE
git reset --soft HEAD~1Undo commit, keep changes staged
git reset --hard HEAD~1Undo commit + discard DESTRUCT
git restore --staged file.txtUnstage file
git restore file.txtDiscard working changes
git reflogΙστορικό HEAD — safety net
git commit --amend --no-editPatch last commit (πριν push)
git push --force-with-leaseForce push (safer) CAREFUL

📄 Dockerfile — Best Practices
# Multi-stage build — Node.js example FROM node:20-alpine AS builder WORKDIR /app COPY package*.json ./ RUN npm ci --only=production COPY . . RUN npm run build # Final stage — minimal image FROM node:20-alpine WORKDIR /app COPY --from=builder /app/dist ./dist COPY --from=builder /app/node_modules ./node_modules USER node # μην τρέχεις ως root! EXPOSE 3000 CMD ["node", "dist/index.js"]

🔐 Security & Secrets Best Practices
  • Ποτέ secrets σε plaintext — χρήση GITHUB_SECRETS, Vault, Azure Key Vault
  • Το .env στο .gitignore — ΠΆΝΤΑ
  • Docker images: μην τρέχεις ως root (USER node)
  • SSH keys: chmod 600 — ποτέ 644
  • Terraform state: remote backend (S3+lock) — ποτέ local σε git
  • Rotate secrets περιοδικά + audit access logs
  • Container scanning: trivy image app:latest
  • Dependency audit: npm audit / pip-audit
  • Principle of Least Privilege σε IAM/service accounts

🚨 Incident Response Checklist
  • Collect: logs, metrics, recent deployments timeline
  • git log --oneline -20 — τι έχει αλλάξει πρόσφατα
  • Rollback deployment: kubectl rollout undo ή git revert
  • Snapshot / backup πριν οποιοδήποτε fix
  • Communicate status στην ομάδα (Slack/Teams channel)
  • Fix σε staging πρώτα — test — μετά production
  • Post-mortem: timeline, root cause, action items
