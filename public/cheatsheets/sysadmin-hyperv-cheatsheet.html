// Power Tips & Survival Checklist
Pre-Maintenance Checklist
  • Snapshot VM πριν οποιαδήποτε αλλαγή
  • Drain cluster node πριν reboot host
  • Επιβεβαίωσε replication AD (repadmin /showrepl)
  • Backup AD System State (wbadmin start systemstatebackup)
  • Σιγουρέψου ότι δεν τρέχει CHKDSK on next boot ήδη
  • Ενημέρωσε users για downtime window
  • Έχεις console access σε περίπτωση που κοπεί το δίκτυο
  • Test-NetConnection σε critical services μετά την αλλαγή
