🎯 Τι είναι το Tenant Migration Assessment V2;

Tenant Migration Assessment V2 Είναι ένα προηγμένο PowerShell script που αναλύει και καταγράφει ολόκληρο το Microsoft 365 tenant σου. Δημιουργεί αναλυτικές αναφορές σε HTML format για:
  • Users & Licenses
  • Groups & Memberships
  • Mailboxes & Permissions
  • SharePoint Sites & Document Libraries
  • OneDrive Usage
  • Teams & Channels
  • Service Plans & Subscriptions

💼 Γιατί είναι Τρομερό Εργαλείο;

📊 Complete Visibility

Πλήρης εικόνα του M365 tenant σε ένα comprehensive HTML report

🔄 Migration Planning

Ιδανικό για tenant-to-tenant migrations - ξέρεις τι θα μεταφέρεις πριν ξεκινήσεις

📈 Audit & Compliance

Καταγράφει permissions, access rights, και configuration για audits

💰 License Optimization

Βλέπεις ακριβώς ποιες licenses χρησιμοποιούνται και από ποιους

🔍 Security Analysis

Ανίχνευση mailbox delegations, shared permissions, και access rights

📝 Documentation

Auto-generated documentation για το tenant configuration

⚙️ Προαπαιτούμενα

1. PowerShell & Modules

# PowerShell 7.x (recommended) winget install Microsoft.PowerShell # Required PowerShell Modules Install-Module Microsoft.Graph -Scope CurrentUser -Force Install-Module ExchangeOnlineManagement -Scope CurrentUser -Force Install-Module Microsoft.Online.SharePoint.PowerShell -Scope CurrentUser -Force Install-Module PnP.PowerShell -Scope CurrentUser -Force

2. Azure AD Permissions

⚠️ Απαιτούνται Admin Rights:
  • Global Administrator (για πλήρη analysis)
  • ή Helpdesk Administrator + SharePoint Administrator + Exchange Administrator

3. Azure App Registration (Certificate-Based Auth)

Γιατί Certificate-Based Authentication;
  • ✅ Πιο ασφαλές από passwords
  • ✅ Ιδανικό για automation & scheduled tasks
  • ✅ Δεν εξαρτάται από user credentials
  • ✅ Δεν απαιτεί MFA bypass

🔐 Azure App Registration - Step by Step

1

Δημιουργία App Registration

  1. Πήγαινε στο Azure Portal: https://portal.azure.com
  2. Azure Active Directory → App registrations → New registration
  3. Όνομα: "TenantMigrationAssessment" (ή όπως θες)
  4. Supported account types: Single tenant
  5. Redirect URI: Άφησέ το κενό
  6. Κλικ Register
2

Καταγραφή Application (client) ID & Tenant ID

# Θα τα βρεις στο Overview page Application (client) ID: 12345678-1234-1234-1234-123456789012 Directory (tenant) ID: 87654321-4321-4321-4321-210987654321
3

API Permissions - Πολύ Σημαντικό!

  1. API permissions → Add a permission → Microsoft Graph
  2. Application permissions (ΟΧΙ Delegated)
  3. Πρόσθεσε τα παρακάτω permissions:
Permission Γιατί το χρειάζεται
User.Read.All Ανάγνωση user profiles & properties
Group.Read.All Ανάγνωση groups & memberships
Directory.Read.All Ανάγνωση directory objects
Organization.Read.All Ανάγνωση tenant information
Sites.Read.All Ανάγνωση SharePoint sites
Files.Read.All Ανάγνωση OneDrive & SharePoint files
Mail.Read Ανάγνωση mailbox information
MailboxSettings.Read Ανάγνωση mailbox settings
Reports.Read.All Ανάγνωση usage reports
⚠️ ΚΡΙΣΙΜΟ: Μετά την προσθήκη των permissions, πρέπει να κάνεις
"Grant admin consent for [Your Organization]"
Αλλιώς το script ΔΕΝ θα τρέξει!
4

Δημιουργία Self-Signed Certificate

# PowerShell - Run as Administrator $certName = "TenantMigrationCert" $cert = New-SelfSignedCertificate ` -Subject "CN=$certName" ` -CertStoreLocation "Cert:\CurrentUser\My" ` -KeyExportPolicy Exportable ` -KeySpec Signature ` -KeyLength 2048 ` -KeyAlgorithm RSA ` -HashAlgorithm SHA256 ` -NotAfter (Get-Date).AddYears(2) # Εμφάνιση Thumbprint (θα το χρειαστείς!) $cert.Thumbprint # Export σε .cer file για upload στο Azure $certPath = "C:\Temp\TenantMigrationCert.cer" Export-Certificate -Cert $cert -FilePath $certPath Write-Host "Certificate Thumbprint: $($cert.Thumbprint)" -ForegroundColor Green Write-Host "Certificate exported to: $certPath" -ForegroundColor Green
5

Upload Certificate στο App Registration

  1. Azure Portal → App registrations → Το App σου
  2. Certificates & secrets → Certificates → Upload certificate
  3. Διάλεξε το .cer file που έφτιαξες
  4. Κλικ Add

🔧 Advanced Configuration

Scheduled Assessment (Task Scheduler)

# Create scheduled task για monthly assessment $action = New-ScheduledTaskAction ` -Execute "PowerShell.exe" ` -Argument "-File C:\Scripts\Perform-TenantAssessment.ps1 -clientId $clientid -tenantId $tenantID -certificateThumbprint $Thumbprint -IncludePlans" $trigger = New-ScheduledTaskTrigger ` -Monthly ` -At "02:00AM" ` -DaysOfMonth 1 Register-ScheduledTask ` -TaskName "TenantAssessment-Monthly" ` -Action $action ` -Trigger $trigger ` -User "SYSTEM" ` -RunLevel Highest

Custom Output Location

# Modify το script για custom output path # Άνοιξε το Perform-TenantAssessment.ps1 και βρες: $OutputPath = ".\AssessmentResults" # Άλλαξε σε: $OutputPath = "D:\TenantReports\$((Get-Date).ToString('yyyy-MM'))"

Email Report Automation

# Πρόσθεσε στο τέλος του script $reportPath = Get-ChildItem -Path ".\AssessmentResults" -Filter "*.html" -Recurse | Sort-Object LastWriteTime -Descending | Select-Object -First 1 Send-MailMessage ` -To "admin@yourdomain.com" ` -From "reports@yourdomain.com" ` -Subject "Tenant Assessment - $(Get-Date -Format 'yyyy-MM-dd')" ` -Body "Tenant assessment completed. Report attached." ` -Attachments $reportPath.FullName ` -SmtpServer "smtp.office365.com" ` -Port 587 ` -UseSsl

🚨 Troubleshooting

❌ Error: "The term 'Connect-MgGraph' is not recognized"

Λύση:
Install-Module Microsoft.Graph -Force -Scope CurrentUser Import-Module Microsoft.Graph

❌ Error: "Insufficient privileges to complete the operation"

Λύση:
  • Έλεγξε ότι έχεις κάνει "Grant admin consent" στο App Registration
  • Βεβαιώσου ότι το App έχει όλα τα απαραίτητα API permissions
  • Περίμενε 5-10 λεπτά μετά το admin consent για propagation

❌ Error: "Certificate with thumbprint [X] not found"

Λύση:
# Έλεγξε αν το certificate υπάρχει Get-ChildItem Cert:\CurrentUser\My | Where-Object {$_.Subject -like "*TenantMigration*"} # Αν δεν υπάρχει, ξαναδημιούργησέ το

❌ Script τρέχει πολύ αργά

Tips για optimization:
  • Μην χρησιμοποιείς όλες τις παραμέτρους αν δεν χρειάζεται
  • Το -IncludeDocumentLibraries είναι πολύ resource-intensive
  • Τρέξε το assessment εκτός business hours
  • Χρησιμοποίησε filtering αν είναι διαθέσιμο

❌ Out of Memory Errors

Λύση:
  • Τρέξε το script σε chunks (κάνε assessments σε specific groups/sites)
  • Κλείσε άλλες εφαρμογές για να ελευθερώσεις RAM
  • Upgrade σε μηχάνημα με περισσότερη μνήμη για μεγάλα tenants
