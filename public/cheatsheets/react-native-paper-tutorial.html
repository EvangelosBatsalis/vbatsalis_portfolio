📱 Τι είναι το React Native Paper;

Το React Native Paper είναι η καλύτερη Material Design library για React Native. Προσφέρει έτοιμα, όμορφα και customizable components που ακολουθούν τις Material Design guidelines.

✨ Material Design 3

Πλήρης υποστήριξη του νέου Material Design 3 με όλα τα σύγχρονα components

🎨 Theming

Εύκολο customization με themes, dark mode, και custom colors

📱 Cross-Platform

Δουλεύει τέλεια σε iOS, Android και Web

♿ Accessibility

Built-in accessibility features για όλους τους χρήστες

🚀 Installation & Setup

Βήμα 1: Δημιουργία Expo Project

npx create-expo-app my-paper-app
cd my-paper-app

Βήμα 2: Installation Dependencies

npm install react-native-paper
npx expo install react-native-safe-area-context
npx expo install @expo/vector-icons
Τέλεια! Τώρα έχεις όλα τα packages που χρειάζεσαι για να ξεκινήσεις.

Βήμα 3: Basic Configuration - App.js

import * as React from 'react'; import { Provider as PaperProvider } from 'react-native-paper'; import { SafeAreaProvider } from 'react-native-safe-area-context'; import MainScreen from './screens/MainScreen'; export default function App() { return ( <SafeAreaProvider> <PaperProvider> <MainScreen /> </PaperProvider> </SafeAreaProvider> ); }
Tip: Το SafeAreaProvider είναι σημαντικό για να αποφύγεις το notch σε iPhone και άλλα κινητά!

Complete Form Example

Registration Form

📧 Email
🔒 Password
🔒 Confirm Password
Register
import * as React from 'react'; import { View, ScrollView, StyleSheet } from 'react-native'; import { TextInput, Button, HelperText, Checkbox, Text, } from 'react-native-paper'; export default function RegisterForm() { const [email, setEmail] = React.useState(''); const [password, setPassword] = React.useState(''); const [confirmPassword, setConfirmPassword] = React.useState(''); const [agreed, setAgreed] = React.useState(false); // Validation Functions const hasEmailErrors = () => { return !email.includes('@'); }; const hasPasswordErrors = () => { return password.length < 6; }; const passwordsMatch = () => { return password === confirmPassword; }; const handleSubmit = () => { if (!hasEmailErrors() && !hasPasswordErrors() && passwordsMatch() && agreed) { console.log('Form submitted!', { email, password }); } }; return ( <ScrollView style={styles.container}> {/* Email Input */} <TextInput label="Email" value={email} onChangeText={setEmail} mode="outlined" keyboardType="email-address" autoCapitalize="none" error={hasEmailErrors()} style={styles.input} left={<TextInput.Icon icon="email" />} /> <HelperText type="error" visible={hasEmailErrors()}> Email address is invalid! </HelperText> {/* Password Input */} <TextInput label="Password" value={password} onChangeText={setPassword} mode="outlined" secureTextEntry error={hasPasswordErrors()} style={styles.input} left={<TextInput.Icon icon="lock" />} /> <HelperText type="error" visible={hasPasswordErrors()}> Password must be at least 6 characters! </HelperText> {/* Confirm Password */} <TextInput label="Confirm Password" value={confirmPassword} onChangeText={setConfirmPassword} mode="outlined" secureTextEntry error={!passwordsMatch()} style={styles.input} left={<TextInput.Icon icon="lock-check" />} /> <HelperText type="error" visible={!passwordsMatch()}> Passwords don't match! </HelperText> {/* Checkbox */} <View style={styles.checkboxContainer}> <Checkbox status={agreed ? 'checked' : 'unchecked'} onPress={() => setAgreed(!agreed)} /> <Text>I agree to terms and conditions</Text> </View> {/* Submit Button */} <Button mode="contained" onPress={handleSubmit} style={styles.button} disabled={ hasEmailErrors() || hasPasswordErrors() || !passwordsMatch() || !agreed } > Register </Button> </ScrollView> ); } const styles = StyleSheet.create({ container: { flex: 1, padding: 16, }, input: { marginBottom: 8, }, checkboxContainer: { flexDirection: 'row', alignItems: 'center', marginVertical: 16, }, button: { marginTop: 16, }, });

🎨 Theming & Customization

Custom Theme

import { MD3LightTheme, MD3DarkTheme } from 'react-native-paper'; const customTheme = { ...MD3LightTheme, colors: { ...MD3LightTheme.colors, primary: '#6200ee', secondary: '#03dac6', tertiary: '#f50057', error: '#b00020', background: '#ffffff', surface: '#ffffff', }, }; // Στο App.js <PaperProvider theme={customTheme}> <App /> </PaperProvider>

Dark Mode Support

import { useColorScheme } from 'react-native'; export default function App() { const colorScheme = useColorScheme(); const theme = colorScheme === 'dark' ? MD3DarkTheme : MD3LightTheme; return ( <PaperProvider theme={theme}> <MainScreen /> </PaperProvider> ); }

Using Theme in Components

import { useTheme } from 'react-native-paper'; function MyComponent() { const theme = useTheme(); return ( <View style={{ backgroundColor: theme.colors.background }}> <Text style={{ color: theme.colors.primary }}> Themed Text </Text> </View> ); }

Available Theme Colors

Color Description Usage
primary Main brand color Buttons, headers, main actions
secondary Secondary brand color FABs, secondary actions
background Screen background Main app background
surface Component surface Cards, dialogs, menus
error Error states Error messages, validation
