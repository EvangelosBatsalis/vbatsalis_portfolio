🔌 Βήμα 6: myDATA Integration (Advanced)

⚠️ Advanced Section

Αυτό το section απαιτεί τεχνικές γνώσεις Python και Frappe development. Αν δεν είσαι developer, μπορείς να παραλείψεις αυτό το βήμα και να εξάγεις τα invoices manually για upload στο myDATA.

Επιλογές για myDATA Integration

Υπάρχουν 3 τρόποι να στείλεις τα invoices στο myDATA:

1. Manual Export

Εξάγεις τα invoices από το ERPNext και τα ανεβάζεις manual στο portal του myDATA.

Πλεονέκτημα: Απλό, δεν χρειάζεται coding

Μειονέκτημα: Χειροκίνητη διαδικασία

2. Custom Script

Γράφεις Python script που καλεί το myDATA API από το ERPNext.

Πλεονέκτημα: Αυτοματοποιημένο

Μειονέκτημα: Χρειάζεται development

3. Frappe App

Δημιουργείς custom Frappe app με πλήρη myDATA integration.

Πλεονέκτημα: Professional, reusable

Μειονέκτημα: Πιο σύνθετο

Option 1: Manual Export (Προτεινόμενο για Αρχάριους)

1 Export Invoices

Πήγαινε στο Sales Invoice List και επίλεξε τα invoices που θέλεις να στείλεις.

Κάνε Export → Excel

2 Format για myDATA

Άνοιξε το Excel και format τα δεδομένα σύμφωνα με τις προδιαγραφές του myDATA:

  • Invoice Type Code (11.2, 2.1 κλπ)
  • AADE Income Classification (E3_561_003 κλπ)
  • VAT Exemption Reason
3 Upload στο myDATA Portal

Μπες στο portal του myDATA και ανέβασε το formatted file.

Option 2: Custom Script (για Developers)

1 myDATA API Setup

Θα χρειαστείς:

  • myDATA API credentials (username, subscription key)
  • Python library για API calls (requests)
2 Custom Script Example

Δημιούργησε ένα Python script:

# mydata_integration.py import frappe import requests import json def send_invoice_to_mydata(invoice_name): """Send Sales Invoice to myDATA""" # Get invoice invoice = frappe.get_doc("Sales Invoice", invoice_name) # Prepare myDATA payload payload = { "issuer": { "vatNumber": invoice.company_tax_id, "country": "GR", "branch": 0 }, "counterpart": { "vatNumber": invoice.tax_id or "", "country": "GR", "branch": 0 }, "invoiceHeader": { "series": "A", "aa": invoice.name.split("-")[-1], "issueDate": invoice.posting_date.isoformat(), "invoiceType": invoice.invoice_type_code or "11.2", "currency": "EUR" }, "invoiceDetails": [] } # Add line items for item in invoice.items: line = { "lineNumber": item.idx, "netValue": item.amount, "vatCategory": 7, # Exempted "vatAmount": 0, "vatExemptionCategory": 16, # Article 24 "incomeClassification": [{ "classificationType": item.aade_income_classification, "classificationCategory": "category1_3", "amount": item.amount }] } payload["invoiceDetails"].append(line) # Call myDATA API api_url = "https://mydata-register.gov.gr/api/v1/SendInvoices" headers = { "aade-user-id": frappe.conf.mydata_user_id, "ocp-apim-subscription-key": frappe.conf.mydata_subscription_key, "Content-Type": "application/json" } response = requests.post(api_url, headers=headers, data=json.dumps(payload)) if response.status_code == 200: result = response.json() # Update invoice with MARK invoice.mydata_mark = result.get("mark") invoice.mydata_uid = result.get("uid") invoice.save() frappe.db.commit() return True else: frappe.throw(f"myDATA Error: {response.text}") return False # Hook to auto-send on submit def on_submit(doc, method): if doc.doctype == "Sales Invoice": send_invoice_to_mydata(doc.name)
3 Add to hooks.py
# hooks.py doc_events = { "Sales Invoice": { "on_submit": "mydata_integration.on_submit" } }
4 Configuration

Πρόσθεσε τα credentials στο site_config.json:

{ "mydata_user_id": "your_username", "mydata_subscription_key": "your_subscription_key" }

🔴 Ασφάλεια

  • ΜΗΝ commit το site_config.json στο Git!
  • Χρησιμοποίησε environment variables για production
  • Κράτα backups των invoices πριν τα στείλεις
  • Test σε sandbox environment πρώτα!

Common Issues & Solutions

❌ Problem: ΦΠΑ εμφανίζεται στο invoice

Solution:

  • Έλεγξε ότι το Item έχει το σωστό Tax Template
  • Βεβαιώσου ότι το template έχει Rate = 0
  • Clear cache: bench clear-cache

❌ Problem: Custom fields δεν εμφανίζονται

Solution:

  • Reload page (Ctrl+Shift+R)
  • Restart bench: bench restart
  • Έλεγξε ότι πάτησες "Update" στο Customize Form

❌ Problem: Δεν μπορώ να submit invoice

Solution:

  • Έλεγξε ότι έχεις συμπληρώσει mandatory fields
  • Βεβαιώσου ότι έχεις Income Account
  • Check error logs: bench console
