Top 20 Must-Know Facts
TopicKey Fact
P1 LicenseConditional Access, Dynamic Groups, Hybrid Azure AD Join
P2 LicensePIM (Privileged Identity Management), Identity Protection, Access Reviews
ReadOnly LockBlocks all POST operations → cannot list storage keys, cannot restart VM
Delete LockPrevents deletion but allows read and modify operations
TagsDo NOT inherit from RG to resources. Use Azure Policy to enforce tagging.
RBAC DenyExplicit Deny wins over any Allow. RBAC is additive otherwise.
Archive RehydrationStandard priority: up to 15 hours. High priority: up to 1 hour.
Premium StorageSupports LRS and ZRS only — no GRS/GZRS geo-replication
Temp DiskNon-persistent. Lost on VM resize/redeploy/stop-deallocate. Never store important data.
Availability Set SLA99.95% — same datacenter, different fault/update domains
Availability Zone SLA99.99% — physically separate datacenters in same region
Deployment SlotsApp Service Standard tier and above. Swap = zero downtime release.
/29 Subnet8 IPs total − 5 Azure reserved = 3 usable for VMs
VNet PeeringNon-transitive. Both directions required. No overlapping address spaces.
NSG Dual-levelAND logic — both Subnet AND NIC NSG must allow for traffic to pass
Standard LBClosed by default. NSG rule required for inbound traffic.
App Gateway vs LBAppGW = L7 (URL routing, WAF, SSL termination) | LB = L4 (TCP/UDP only)
Activity LogControl-plane events (WHO did WHAT WHEN). 90-day retention.
Soft Delete (Backup)14-day recovery window after backup data is deleted
ASR vs BackupASR = Disaster Recovery (RPO minutes) | Backup = restore past data (RPO hours)
