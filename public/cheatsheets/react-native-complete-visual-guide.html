Feature ScrollView FlatList

Pressable vs TouchableOpacity

TouchableOpacity (Recommended ✓)

Recommendations:
  • ✅ Χρησιμοποίησε TouchableOpacity για buttons (πιο απλό)
  • ✅ Χρησιμοποίησε FlatList αντί για ScrollView για μεγάλες λίστες
  • ✅ Πάντα βάλε width και height στα Images
  • ✅ Χρησιμοποίησε activeOpacity={0.7} για feedback

Complete Typography Scale

H1 - Heading 1 (48px / 900)
H2 - Heading 2 (36px / 800)
H3 - Heading 3 (28px / 700)
H4 - Heading 4 (24px / 700)
H5 - Heading 5 (20px / 600)
H6 - Heading 6 (18px / 600)

Small Text - Secondary information (14px / 400)
Caption - Labels and captions (12px / 400)
Typography Best Practices:
  • ✅ Χρησιμοποίησε lineHeight για καλύτερη αναγνωσιμότητα (1.5-1.6x το fontSize)
  • ✅ Κράτησε το letterSpacing subtle (-1 έως 2)
  • ✅ Χρησιμοποίησε fontWeight: '600' ή '700' για έμφαση
  • ✅ Προτίμησε textAlign: 'left' για μεγάλα κείμενα
  • ✅ Χρησιμοποίησε textShadow για contrast σε εικόνες
  • ✅ Κράτησε typography scale consistent (1.2-1.5 ratio)

import { useState, useEffect } from 'react'; import { View, Text, FlatList, ActivityIndicator } from 'react-native'; export default function UsersScreen() { const [users, setUsers] = useState([]); const [loading, setLoading] = useState(true); const [error, setError] = useState(null); useEffect(() => { fetchUsers(); }, []); const fetchUsers = async () => { try { const response = await fetch('https://api.example.com/users'); if (!response.ok) { throw new Error('Network response was not ok'); } const data = await response.json(); setUsers(data); } catch (err) { setError(err.message); } finally { setLoading(false); } }; if (loading) { return ( <View style={styles.center}> <ActivityIndicator size="large" color="#667eea" /> </View> ); } if (error) { return ( <View style={styles.center}> <Text style={styles.error}>Error: {error}</Text> </View> ); } return ( <FlatList data={users} renderItem={({ item }) => <UserItem user={item} />} keyExtractor={item => item.id.toString()} /> ); }

Custom API Hook

import { useState, useEffect } from 'react'; export const useApi = (url) => { const [data, setData] = useState(null); const [loading, setLoading] = useState(true); const [error, setError] = useState(null); const fetchData = async () => { try { setLoading(true); const response = await fetch(url); if (!response.ok) { throw new Error('API request failed'); } const json = await response.json(); setData(json); setError(null); } catch (err) { setError(err.message); } finally { setLoading(false); } }; useEffect(() => { fetchData(); }, [url]); return { data, loading, error, refetch: fetchData }; }; // Usage function MyComponent() { const { data, loading, error, refetch } = useApi( 'https://api.example.com/data' ); if (loading) return <Loading />; if (error) return <Error message={error} />; return <DataDisplay data={data} onRefresh={refetch} />; }
API Best Practices:
  • ✅ Πάντα κάνε error handling (try/catch)
  • ✅ Δείξε loading states στον χρήστη
  • ✅ Χρησιμοποίησε custom hooks για reusability
  • ✅ Κάνε cancel των requests όταν το component unmounts
  • ✅ Χρησιμοποίησε AbortController για timeouts

8. 📱 SafeAreaProvider - The Correct Way

ΣΗΜΑΝΤΙΚΟ! Το SafeAreaView από το react-native έχει γίνει deprecated! Χρησιμοποίησε το SafeAreaProvider από το react-native-safe-area-context!

Installation

# Install the library npx expo install react-native-safe-area-context

Correct Setup με SafeAreaProvider

import React from 'react'; import { View, Text } from 'react-native'; import { SafeAreaProvider, SafeAreaView } from 'react-native-safe-area-context'; export default function App() { return ( <SafeAreaProvider> <SafeAreaView style={{ flex: 1 }}> <View style={{ flex: 1, padding: 20 }}> <Text>Safe content!</Text> </View> </SafeAreaView> </SafeAreaProvider> ); }

Using useSafeAreaInsets Hook

import { useSafeAreaInsets } from 'react-native-safe-area-context'; function MyScreen() { const insets = useSafeAreaInsets(); return ( <View style={{ flex: 1, paddingTop: insets.top, paddingBottom: insets.bottom, paddingLeft: insets.left, paddingRight: insets.right, }} > <Text>Content with safe area padding</Text> </View> ); }

Complete App Structure

import React from 'react'; import { NavigationContainer } from '@react-navigation/native'; import { SafeAreaProvider } from 'react-native-safe-area-context'; import RootNavigator from './navigation/RootNavigator'; export default function App() { return ( <SafeAreaProvider> <NavigationContainer> <RootNavigator /> </NavigationContainer> </SafeAreaProvider> ); }
Pro Tip: Βάλε το SafeAreaProvider στο root level του app σου (App.js), και μετά χρησιμοποίησε SafeAreaView ή useSafeAreaInsets σε οποιαδήποτε screen!
