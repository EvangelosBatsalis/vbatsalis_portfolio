🤔 Τι είναι το Formik και το Yup;

📋 Formik

Form Management Library που διαχειρίζεται:

  • ✅ Form State (values, errors, touched)
  • ✅ Form Validation
  • ✅ Form Submission
  • ✅ Error Handling
  • ✅ Field-level validation

✔️ Yup

Schema Validation Library που προσφέρει:

  • ✅ Declarative validation rules
  • ✅ Built-in validators (email, min, max)
  • ✅ Custom error messages
  • ✅ Type checking
  • ✅ Async validation
Σε μία πρόταση: Το Formik διαχειρίζεται το form state, το Yup ελέγχει αν τα δεδομένα είναι σωστά!

⚖️ Πότε να χρησιμοποιήσεις Formik;

🟢 Απλή Προσέγγιση (useState)

✅ Πλεονεκτήματα:
  • Απλό και γρήγορο
  • Καλό για μικρές φόρμες (2-5 πεδία)
  • Δεν χρειάζεται extra dependencies
  • Εύκολο debugging
  • Λιγότερο boilerplate
❌ Μειονεκτήματα:
  • Πολύς κώδικας σε μεγάλες φόρμες
  • Repetitive validation code
  • Δύσκολο error handling
  • Χειροκίνητο touched state management
Χρησιμοποίησέ το όταν: Έχεις απλή φόρμα login/register με 2-5 πεδία

🔴 Formik + Yup

✅ Πλεονεκτήματα:
  • Cleaner code σε μεγάλες φόρμες
  • Declarative validation με Yup
  • Automatic error handling
  • Built-in touched state
  • Εύκολο multi-step forms
  • Reusable validation schemas
❌ Μειονεκτήματα:
  • Extra dependencies (+80KB)
  • Learning curve
  • Περισσότερο boilerplate αρχικά
  • Πιο δύσκολο debugging
Χρησιμοποίησέ το όταν: Έχεις φόρμα με 10+ πεδία ή πολύπλοκο validation

✔️ Yup Validation Schemas

Το Yup δημιουργεί "schemas" που περιγράφουν πώς πρέπει να είναι τα δεδομένα σου.

Βασικό Validation Schema

import * as Yup from 'yup'; // Δημιουργία validation schema const LoginSchema = Yup.object().shape({ // Email validation email: Yup.string() .email('Invalid email address') .required('Email is required'), // Password validation password: Yup.string() .min(6, 'Password must be at least 6 characters') .required('Password is required'), });

Όλοι οι Yup Validators

Validator Περιγραφή Παράδειγμα
.required() Υποχρεωτικό πεδίο .required('Required')
.email() Έλεγχος email .email('Invalid email')
.min() Minimum μήκος/αριθμός .min(6, 'Too short')
.max() Maximum μήκος/αριθμός .max(50, 'Too long')
.matches() Regex pattern .matches(/^[A-Z]/, 'Must start with capital')
.oneOf() Πρέπει να είναι ένα από .oneOf([ref('password')], 'Passwords must match')
.url() Έλεγχος URL .url('Must be valid URL')
.positive() Θετικός αριθμός .positive('Must be positive')

Advanced Validation Examples

1. Phone Number Validation

const phoneSchema = Yup.string() .matches( /^[0-9]{10}$/, 'Phone number must be exactly 10 digits' ) .required('Phone is required');

2. Password Confirmation

const RegisterSchema = Yup.object().shape({ password: Yup.string() .min(8, 'Password must be at least 8 characters') .matches( /^(?=.*[a-z])(?=.*[A-Z])(?=.*\d)/, 'Must contain uppercase, lowercase and number' ) .required('Required'), confirmPassword: Yup.string() .oneOf([Yup.ref('password')], 'Passwords must match') .required('Required'), });

3. Conditional Validation

const ConditionalSchema = Yup.object().shape({ hasShipping: Yup.boolean(), // Shipping address είναι required μόνο αν hasShipping = true shippingAddress: Yup.string().when('hasShipping', { is: true, then: schema => schema.required('Address required'), otherwise: schema => schema, }), });

4. Age Validation

const ageSchema = Yup.number() .min(18, 'Must be at least 18 years old') .max(100, 'Invalid age') .required('Age is required');

import * as React from 'react'; import { View, StyleSheet } from 'react-native'; import { Formik } from 'formik'; import * as Yup from 'yup'; import { TextInput, Button, HelperText } from 'react-native-paper'; // 1. Δημιουργία Validation Schema const LoginSchema = Yup.object().shape({ email: Yup.string() .email('Invalid email address') .required('Email is required'), password: Yup.string() .min(6, 'Password must be at least 6 characters') .required('Password is required'), }); export default function LoginScreen() { return ( <Formik // 2. Initial Values initialValues={{ email: '', password: '', }} // 3. Validation Schema validationSchema={LoginSchema} // 4. Submit Handler onSubmit={(values, { setSubmitting }) => { console.log('Form submitted!', values); // Your login logic here setTimeout(() => { setSubmitting(false); }, 1000); }} > {({ handleChange, handleBlur, handleSubmit, values, errors, touched, isSubmitting }) => ( <View style={styles.container}> {/* Email Input */} <TextInput label="Email" value={values.email} onChangeText={handleChange('email')} onBlur={handleBlur('email')} mode="outlined" keyboardType="email-address" autoCapitalize="none" error={touched.email && errors.email} left={<TextInput.Icon icon="email" />} /> <HelperText type="error" visible={touched.email && errors.email}> {errors.email} </HelperText> {/* Password Input */} <TextInput label="Password" value={values.password} onChangeText={handleChange('password')} onBlur={handleBlur('password')} mode="outlined" secureTextEntry error={touched.password && errors.password} left={<TextInput.Icon icon="lock" />} /> <HelperText type="error" visible={touched.password && errors.password}> {errors.password} </HelperText> {/* Submit Button */} <Button mode="contained" onPress={handleSubmit} loading={isSubmitting} style={styles.button} > Login </Button> </View> )} </Formik> ); } const styles = StyleSheet.create({ container: { padding: 20, }, button: { marginTop: 16, }, });
Πώς λειτουργεί:
  1. Ορίζεις το validation schema με Yup
  2. Το Formik διαχειρίζεται το state αυτόματα
  3. Χρησιμοποιείς τα errors και touched για UI feedback
  4. Το handleSubmit καλείται μόνο αν το validation περνάει!

🚀 Advanced Patterns

1. Field Array - Dynamic Form Fields

Για forms με dynamic αριθμό πεδίων (π.χ. add multiple phone numbers):

import { FieldArray } from 'formik'; const PhoneSchema = Yup.object().shape({ phones: Yup.array().of( Yup.string().matches(/^[0-9]{10}$/, 'Invalid phone') ), }); <Formik initialValues={{ phones: [''] }} validationSchema={PhoneSchema} > {({ values }) => ( <FieldArray name="phones"> {({ push, remove }) => ( <View> {values.phones.map((phone, index) => ( <View key={index}> <TextInput label={`Phone ${index + 1}`} value={phone} onChangeText={handleChange(`phones.${index}`)} /> <Button onPress={() => remove(index)}>Remove</Button> </View> ))} <Button onPress={() => push('')}>Add Phone</Button> </View> )} </FieldArray> )} </Formik>

2. Custom Validation Function

const CustomSchema = Yup.object().shape({ username: Yup.string() .test( 'checkUsername', 'Username already taken', async (value) => { // Call your API to check username const response = await fetch(`/api/check-username/${value}`); const data = await response.json(); return data.available; } ) .required(), });

3. Reusable Form Components

// FormikTextInput.js - Reusable component import { useField } from 'formik'; export const FormikTextInput = ({ name, label, ...props }) => { const [field, meta] = useField(name); return ( <> <TextInput label={label} value={field.value} onChangeText={field.onChange(name)} onBlur={field.onBlur(name)} error={meta.touched && meta.error} {...props} /> <HelperText type="error" visible={meta.touched && meta.error}> {meta.error} </HelperText> </> ); }; // Usage <Formik ...> <FormikTextInput name="email" label="Email" /> <FormikTextInput name="password" label="Password" secureTextEntry /> </Formik>

📄 Quick Cheatsheet

Common Yup Validators

Code What it does
.required('msg') Field is required
.email('msg') Valid email format
.min(6, 'msg') Minimum length/number
.max(50, 'msg') Maximum length/number
.matches(/regex/, 'msg') Match regex pattern
.oneOf([ref('field')], 'msg') Match another field

Formik Props

Property Type Description
values object Current form values
errors object Validation errors
touched object Which fields were touched
handleChange function Update field value
handleBlur function Mark field as touched
handleSubmit function Submit the form
isSubmitting boolean Is form submitting?
setFieldValue function Manually set field value
