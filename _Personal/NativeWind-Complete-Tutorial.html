ΚΕΦΑΛΑΙΟ 1

Τι είναι το NativeWind;

Με απλά λόγια: Το NativeWind σου επιτρέπει να γράφεις styles για React Native χρησιμοποιώντας Tailwind CSS classes. Αντί να γράφεις StyleSheet.create, απλά βάζεις classes όπως bg-blue-500 p-4 rounded-xl και έχεις τελειώσει!

Γιατί να το χρησιμοποιήσεις;

🚀 Λόγος #1: Γρηγορότερο Development

Αντί να γράφεις 20 γραμμές code για ένα button, γράφεις μία γραμμή με classes. Boom, done!

🎨 Λόγος #2: Consistency (Συνέπεια)

Όλο το app σου θα έχει ίδια spacing (8px, 16px, 24px...), ίδια colors, ίδιο style. Δεν θα έχεις ένα button με 15px padding και άλλο με 17px "γιατί έτσι".

💪 Λόγος #3: Professional Design

Το Tailwind έχει built-in design system με color palettes και spacing scale που κάνουν το app σου να φαίνεται σύγχρονο χωρίς να είσαι designer!

❌ Παλιός Τρόπος

const styles = StyleSheet.create({
  button: {
    backgroundColor: '#3b82f6',
    paddingVertical: 16,
    paddingHorizontal: 24,
    borderRadius: 12,
  }
});

<View style={styles.button}>
  <Text>Click</Text>
</View>

✅ Με NativeWind

<View className="bg-blue-500 py-4 px-6 rounded-xl">
  <Text className="text-white font-semibold">
    Click
  </Text>
</View>

Μία γραμμή, πολύ πιο readable!

Εγκατάσταση (Βήμα-Βήμα)

Ακολούθησε αυτά τα βήματα προσεκτικά. Είναι το setup που θα χρησιμοποιήσεις για το Family Organizer app!

Βήμα 1: Εγκατάσταση Packages

# Κύρια packages
npm install nativewind
npm install react-native-reanimated@~3.17.4
npm install react-native-safe-area-context@5.4.0

# Dev dependencies
npm install --save-dev tailwindcss@^3.4.17
npm install --save-dev prettier-plugin-tailwindcss@^0.5.11

Τι κάνει το καθένα;

nativewind: Το κύριο library που μετατρέπει Tailwind classes σε React Native styles

react-native-reanimated: Για animations

react-native-safe-area-context: Φροντίζει τα safe areas (notch, status bar)

Βήμα 2: Tailwind Config

npx tailwindcss init

Άνοιξε το tailwind.config.js και βάλε:

module.exports = {
  content: [
    "./App.{js,jsx,ts,tsx}",
    "./app/**/*.{js,jsx,ts,tsx}",
    "./components/**/*.{js,jsx,ts,tsx}"
  ],
  presets: [require("nativewind/preset")],
  theme: {
    extend: {},
  },
  plugins: [],
}

Φτιάξε global.css στο root:

Flexbox - Το Μυστικό του Layout

Το Flexbox είναι ο τρόπος με τον οποίο τοποθετείς τα πράγματα στην οθόνη. Σκέψου το σαν Tetris - πρέπει να ξέρεις πώς να βάλεις τα κομμάτια στη σωστή θέση!

Βασικό Concept: flex-direction

Box 1
Box 2
Box 3
flex-col (default)
Το ένα ΚΑΤΩ από το άλλο
Box 1
Box 2
Box 3
flex-row
Το ένα ΔΙΠΛΑ στο άλλο
// Vertical (Column) - Default
<View className="flex-col">
  <Text>Box 1</Text>
  <Text>Box 2</Text>
</View>

// Horizontal (Row)
<View className="flex-row">
  <Text>Box 1</Text>
  <Text>Box 2</Text>
</View>

Alignment - Κεντράρισμα

🎯 Δύο Κύριες Ιδιότητες

justify-content: Ελέγχει τοποθέτηση στον ΚΥΡΙΟ άξονα

items (align-items): Ελέγχει τοποθέτηση στον ΔΕΥΤΕΡΕΥΟΝΤΑ άξονα

justify-content Options:

justify-start
justify-center
justify-end
justify-between
justify-around

items Options:

items-start
items-center
items-end
items-stretch

💼 Use Case: App Header

Logo αριστερά, menu δεξιά:

<View className="flex-row items-center justify-between p-4 bg-white">
  <Text className="text-xl font-bold">Family Organizer</Text>
  <Text>☰</Text>
</View>

Γιατί δουλεύει:

flex-row = Βάλε τα δίπλα-δίπλα

items-center = Κεντράρισμα vertically

justify-between = Πρώτο αριστερά, δεύτερο δεξιά

flex-1: Η Μαγική Class

🪄 Τι κάνει;

Το flex-1 λέει: "Πάρε όσο χώρο μπορείς!". Χρησιμοποιείται στο κύριο container για να πάρει όλο το screen.

❌ Χωρίς flex-1

<View className="items-center justify-center">
  <Text>Μικρό box</Text>
</View>

✅ Με flex-1

<View className="flex-1 items-center justify-center">
  <Text>Όλο το screen!</Text>
</View>
💡 Golden Rule: Στο React Native, ΠΑΝΤΑ βάζουμε flex-1 στο top-level View του screen!
ΚΕΦΑΛΑΙΟ 4

Spacing - Padding & Margin

Το spacing είναι ο "αέρας" γύρω από τα elements. Αυτό που κάνει το app σου να φαίνεται professional αντί για cramped (στριμωγμένο)!

Padding vs Margin

📦 Η διαφορά:

Padding (p): Χώρος ΜΕΣΑ στο box, μεταξύ περιεχομένου και άκρων

Margin (m): Χώρος ΕΞΩ από το box, μεταξύ box και γειτόνων

ΠΕΡΙΕΧΟΜΕΝΟ

↑ Padding (μπλε)

Margin (κόκκινο)

// Padding παντού
<View className="p-4">16px σε όλες τις πλευρές</View>

// Padding horizontal (αριστερά & δεξιά)
<View className="px-4">16px αριστερά και δεξιά</View>

// Padding vertical (πάνω & κάτω)
<View className="py-4">16px πάνω και κάτω</View>

// Συγκεκριμένες πλευρές
<View className="pt-4">Top only</View>
<View className="pb-4">Bottom only</View>
<View className="pl-4">Left only</View>
<View className="pr-4">Right only</View>

🎯 Το Spacing Scale:

0 = 0px
1 = 4px
2 = 8px
3 = 12px
4 = 16px ⭐
5 = 20px
6 = 24px
8 = 32px
10 = 40px
12 = 48px
💡 Golden Rule: Χρησιμοποίησε p-4 για τα περισσότερα screens και cards. Είναι το sweet spot!

Πότε χρησιμοποιώ τι;

📱 Screen Container

  <View className="p-4">
    {/* Όλο το περιεχόμενο */}
  </View>
</SafeAreaView>

🎴 Card Component

<View className="bg-white p-4 rounded-xl mb-4">
  <Text className="font-bold mb-2">Title</Text>
  <Text>Description</Text>
</View>

🔘 Button

<Pressable className="bg-blue-500 py-4 px-6 rounded-xl">
  <Text className="text-white font-semibold">Click</Text>
</Pressable>

Φτιάχνοντας Components

Ας φτιάξουμε τα βασικά components που θα χρησιμοποιήσεις στο Family Organizer!

Button Component

import { Pressable, Text } from 'react-native';

function PrimaryButton({ title, onPress }) {
  return (
    <Pressable
      onPress={onPress}
      className="bg-blue-500 py-4 px-6 rounded-xl active:bg-blue-600"
    >
      <Text className="text-white text-center font-semibold">
        {title}
      </Text>
    </Pressable>
  );
}

Card Component

function Card({ title, description }) {
  return (
    <View className="bg-white p-4 rounded-xl shadow-lg mb-4">
      <Text className="text-lg font-bold text-gray-900 mb-2">
        {title}
      </Text>
      <Text className="text-sm text-gray-600">
        {description}
      </Text>
    </View>
  );
}

Input Component

function InputField({ label, placeholder, value, onChangeText }) {
  return (
    <View className="mb-4">
      <Text className="text-sm font-semibold text-gray-700 mb-2">
        {label}
      </Text>
      <TextInput
        className="bg-white border border-gray-300 rounded-xl px-4 py-3"
        placeholder={placeholder}
        value={value}
        onChangeText={onChangeText}
      />
    </View>
  );
}
