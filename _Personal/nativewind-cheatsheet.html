Introduction

Το NativeWind σου επιτρέπει να χρησιμοποιείς Tailwind CSS classes για να στυλάρεις React Native components. Γράφεις className="..." αντί για style={...} και όλα μετατρέπονται αυτόματα σε native styles!

💡 Πώς λειτουργεί:
Γράφεις: className="flex-1 bg-blue-500 p-4"
Γίνεται: style={{ flex: 1, backgroundColor: '#3b82f6', padding: 16 }}
✅ Τι υποστηρίζεται:
• Όλα τα Tailwind utility classes
• Responsive design (sm:, md:, lg:)
• Dark mode (dark:)
• Custom values με [] brackets
• Container queries
• Animations

Βασικό Παράδειγμα

import { View, Text } from 'react-native'; export default function App() { return ( <View className="flex-1 items-center justify-center bg-white"> <Text className="text-2xl font-bold text-blue-500"> Hello NativeWind! 🎨 </Text> </View> ); }

Spacing (Padding & Margin)

Padding και Margin utilities. Τα νούμερα πολλαπλασιάζονται με 4 (π.χ. p-4 = 16px).

⚠️ Προσοχή: Το React Native δεν υποστηρίζει negative margins όπως το web!

pr-{n} paddingRight: n * 4 Right padding μόνο
pb-{n} paddingBottom: n * 4 Bottom padding μόνο
pl-{n} paddingLeft: n * 4 Left padding μόνο

Platform Differences

Διαφορές μεταξύ React Native και Web - τι να προσέξεις!

⚠️ Σημαντικές Διαφορές:
Feature Web Support React Native Support Λύση
Negative Margins ✅ Full support ❌ Not supported Χρησιμοποίησε padding ή absolute positioning
Hover States ✅ Works ❌ No hover on mobile Χρησιμοποίησε Pressable με onPressIn/Out
Focus States ✅ Works ⚠️ Limited Manual focus state management
Shadows ✅ box-shadow ⚠️ Platform specific (iOS vs Android) Χρησιμοποίησε shadow classes (αυτόματα cross-platform)
Transform Origin ✅ Full support ❌ Limited Manual calculation needed
Z-Index ✅ Works everywhere ⚠️ iOS only (Android uses render order) Αλλάξε render order για Android
Percentage Heights ✅ Works ⚠️ Needs parent with defined height Χρησιμοποίησε flex-1 αντί για h-full

Best Practices για Cross-Platform

✅ Do's:
• Χρησιμοποίησε flex-1 αντί για percentage heights
• Χρησιμοποίησε gap αντί για margins μεταξύ items
• Χρησιμοποίησε NativeWind shadow classes (αυτόματα cross-platform)
• Test σε πραγματικές συσκευές, όχι μόνο emulator
❌ Don'ts:
• Μην χρησιμοποιείς negative margins
• Μην βασίζεσαι σε hover states για mobile
• Μην χρησιμοποιείς web-specific CSS properties
• Μην ξεχνάς τα SafeAreaView για notches
