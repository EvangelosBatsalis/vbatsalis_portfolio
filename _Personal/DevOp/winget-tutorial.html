🚀 WinGet Tutorial

Windows Package Manager - Ο Σύγχρονος Τρόπος Διαχείρισης Εφαρμογών

📖 Τι είναι το WinGet;

WinGet (Windows Package Manager) Είναι το επίσημο command-line εργαλείο της Microsoft για την εγκατάσταση, αναβάθμιση και διαχείριση εφαρμογών στα Windows 10/11. Είναι παρόμοιο με το apt (Linux), brew (macOS), ή chocolatey (Windows).

✨ Πλεονεκτήματα

  • Γρήγορη εγκατάσταση εφαρμογών χωρίς GUI
  • Αυτοματοποίηση εγκαταστάσεων
  • Κεντρική διαχείριση όλων των εφαρμογών
  • Επίσημο repository της Microsoft
  • Δωρεάν και built-in στα Windows 11

🔧 Εγκατάσταση WinGet

Windows 11: Το WinGet είναι προεγκατεστημένο!
Windows 10: Εγκατάστησε το App Installer από το Microsoft Store

Έλεγχος Εγκατάστασης

winget --version # Αναμενόμενο output: v1.7.xxxxx ή νεότερο

🎯 Βασικές Εντολές

1. Αναζήτηση Εφαρμογών (Search)

# Αναζήτηση με όνομα winget search powershell # Αναζήτηση με wildcard winget search "visual studio" # Πιο λεπτομερής αναζήτηση winget search chrome --source winget

Παράδειγμα Output:

Name Id Version Source ---------------------------------------------------------------- PowerShell Microsoft.PowerShell 7.4.1 winget Windows PowerShell Microsoft.PowerShell.Preview 7.5.0 winget

2. Εγκατάσταση Εφαρμογών (Install)

# Βασική εγκατάσταση winget install Microsoft.PowerShell # Εγκατάσταση με συγκεκριμένη έκδοση winget install Microsoft.PowerShell --version 7.4.1 # Σιωπηλή εγκατάσταση (χωρίς UI) winget install Microsoft.PowerShell --silent # Αποδοχή όλων των licenses αυτόματα winget install Microsoft.PowerShell --accept-package-agreements --accept-source-agreements
Tip: Χρησιμοποίησε το --id flag για ακρίβεια όταν υπάρχουν πολλά αποτελέσματα

3. Λίστα Εγκατεστημένων (List)

# Όλες οι εγκατεστημένες εφαρμογές winget list # Φιλτράρισμα με όνομα winget list powershell # Έλεγχος για updates winget list --upgrade-available

4. Ενημέρωση Εφαρμογών (Update/Upgrade)

# Ενημέρωση μιας εφαρμογής winget upgrade Microsoft.PowerShell # Ενημέρωση ΟΛΩΝ των εφαρμογών winget upgrade --all # Ενημέρωση χωρίς αλληλεπίδραση winget upgrade --all --silent --accept-package-agreements
⚠️ Προσοχή: Το winget upgrade --all μπορεί να πάρει αρκετή ώρα αν έχεις πολλές εφαρμογές. Εκτέλεσέ το όταν έχεις χρόνο!

5. Απεγκατάσταση (Uninstall)

# Απεγκατάσταση με ID winget uninstall Microsoft.PowerShell # Σιωπηλή απεγκατάσταση winget uninstall Microsoft.PowerShell --silent

6. Πληροφορίες Πακέτου (Show)

# Λεπτομερείς πληροφορίες winget show Microsoft.PowerShell

🎨 Χρήσιμες Παράμετροι

Παράμετρος Περιγραφή
--silent Σιωπηλή εγκατάσταση χωρίς GUI
--interactive Εμφάνιση του installer GUI
--accept-package-agreements Αυτόματη αποδοχή package licenses
--accept-source-agreements Αυτόματη αποδοχή source agreements
--version Συγκεκριμένη έκδοση προς εγκατάσταση
--location Προσαρμοσμένη τοποθεσία εγκατάστασης
--scope user ή machine (για όλους τους users)
--source Επιλογή source (winget, msstore, κτλ)

💼 Πρακτικά Παραδείγματα

Σενάριο 1: Setup Νέου Υπολογιστή

# Εγκατάσταση essential tools winget install Microsoft.PowerShell --silent winget install Google.Chrome --silent winget install Microsoft.VisualStudioCode --silent winget install 7zip.7zip --silent winget install Git.Git --silent winget install Docker.DockerDesktop --silent

Σενάριο 2: Developer Setup

Σενάριο 3: Εβδομαδιαία Συντήρηση

# Έλεγχος για updates winget list --upgrade-available # Update όλων των εφαρμογών winget upgrade --all --silent --accept-package-agreements

🔍 Advanced Tips

Export/Import Εγκατεστημένων Εφαρμογών

# Export λίστας εγκατεστημένων winget export -o C:\backup\apps.json # Import σε νέο μηχάνημα winget import -i C:\backup\apps.json --accept-package-agreements
Pro Tip: Χρησιμοποίησε το export/import για γρήγορο setup νέων μηχανημάτων!

Δημιουργία Batch Script για Automation

# Δημιούργησε ένα install-apps.bat αρχείο @echo off echo Installing applications... winget install Microsoft.PowerShell --silent --accept-package-agreements winget install Google.Chrome --silent --accept-package-agreements winget install Microsoft.VisualStudioCode --silent --accept-package-agreements echo Installation complete! pause

Χρήση με PowerShell Scripting

# PowerShell script για mass installation $apps = @( "Microsoft.PowerShell", "Google.Chrome", "Microsoft.VisualStudioCode", "Git.Git" ) foreach ($app in $apps) { Write-Host "Installing $app..." -ForegroundColor Green winget install $app --silent --accept-package-agreements }

❓ Συχνές Ερωτήσεις

Q: Πώς βρίσκω το σωστό Package ID;

Χρησιμοποίησε το winget search [όνομα] και δες την στήλη "Id". Για ακρίβεια, χρησιμοποιείς το ID αντί για το όνομα.

Q: Το WinGet δεν αναγνωρίζει εγκατεστημένες εφαρμογές;

Εφαρμογές που εγκαταστάθηκαν πριν το WinGet μπορεί να μην εμφανίζονται. Το WinGet διαχειρίζεται κυρίως εφαρμογές που εγκατέστησε το ίδιο.

Q: Μπορώ να χρησιμοποιήσω το WinGet σε scripts;

Ναι! Είναι ιδανικό για automation. Χρησιμοποίησε τα --silent και --accept-*-agreements flags.

🚨 Troubleshooting

Πρόβλημα: "winget" δεν αναγνωρίζεται

Λύση:
  1. Εγκατάστησε το "App Installer" από το Microsoft Store
  2. Κάνε restart το PowerShell/Terminal
  3. Ενημέρωσε τα Windows στην τελευταία έκδοση

Πρόβλημα: "Agreement required"

# Πρόσθεσε αυτά τα flags --accept-package-agreements --accept-source-agreements
