# 💛 Cheatsheets & Tutorials: Πώς να προσθέσεις νέα!

Επειδή ο τρόπος που το φτιάξαμε είναι **"anti-CMS"**, δηλαδή γρήγορος, ελαφρύς και 100% ασφαλής από React Errors, η προσθήκη ενός νέου cheatsheet ή tutorial είναι πάρα πολύ απλή.

Ακολούθησε αυτά τα **3 γρήγορα βήματα**:

## Βήμα 1: Αποθήκευση του αρχείου
Γράψε τον κώδικά σου (ή κάνε export από το Notion/Markdown app που χρησιμοποιείς) σε ένα αρχείο HTML. Σιγουρέψου ότι φαίνεται όμορφο.
- Παράδειγμα ονόματος: `azure-104-notes.html`

## Βήμα 2: Τοποθέτηση του αρχείου στον σωστό φάκελο
Μετέφερε το αρχείο σου **μέσα στον φάκελο**:
`public/cheatsheets/`
Έτσι, ο Next.js web server θα το σερβίρει αυτόματα σε όλους, γρήγορα και με τέλειο styling, απλά πηγαίνοντας στο `/cheatsheets/azure-104-notes.html`!

## Βήμα 3: Προσθήκη της κάρτας στο Κουμπί (UI)
Άνοιξε το αρχείο:
`components/cheats-and-tuts.tsx`

Στην αρχή του αρχείου (περίπου γραμμή 8), θα δεις ένα array που γράφει `const cheatsheets = [`.
Πρόσθεσε μια νέα κάρτα βάζοντας άλλο ένα block με `{ ... }` στο τέλος της λίστας, ακριβώς έτσι:

```javascript
  {
    title: "Το Νέο μου Τέλειο Tutorial!",
    description: "Μια μικρή ωραία περιγραφή για το τι αφορά.",
    category: "Azure",
    date: "2026-05", // Ή ό,τι ημερομηνία θες
    link: "/cheatsheets/azure-104-notes.html" // <- ΕΔΩ ΒΑΖΕΙΣ ΤΟ ΑΚΡΙΒΕΣ ΟΝΟΜΑ!
  }
```

> **Προσοχή!** Μην ξεχάσεις να βάλεις ένα κόμμα (`,`) στο προηγούμενο block, αν βγάζει κόκκινο error ο Editor σου!
